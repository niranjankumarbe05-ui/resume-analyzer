# Resume Analyzer

A simple Flask-based web application that analyzes resumes and provides basic insights.

---

## Features

- Upload PDF resume
- Extract text from resume
- Analyze resume content
- Generate basic insights

---

## Tech Stack

- Backend: Python (Flask)
- Frontend: HTML, CSS
- Libraries: PyPDF / NLP-based processing

---

resume-analyzer/

│   └── index.html

## How to Run Locally

1. Clone the repository
git clone https://github.com/niranjankumarbe05-ui/resume-analyzer.git
cd resume-analyzer

2. Install dependencies

pip install -r requirements.txt

3. Run the application

python app.py

4. Open in browser

http://127.0.0.1:5000
